
Basic Chatbot.py

A Basic Chatbot is a simple Python-based application that can interact with users through text messages. It uses predefined responses to answer common questions and provide basic conversation features. The chatbot takes user input, processes the message using conditional statements or simple logic, and returns an appropriate response.



Features:

User-friendly text-based conversation
Responds to greetings and common queries
Handles basic questions and answers
Uses Python functions and conditional statements
Runs through the command line/terminal
